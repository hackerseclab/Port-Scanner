# ⚡ Port Scanner

### Fast & Lightweight TCP Port Scanning Tool

> **"Learn networks. Understand security. Build responsibly."**

A simple and efficient **Python-based TCP Port Scanner** created for **cybersecurity learning**, **network analysis**, and **authorized security testing**.

This tool helps users understand open ports, available services, and basic network security concepts through practical scanning.

# 📦 Installation

Clone the repository:

```bash
git clone https://github.com/hackerseclab/Port-Scanner.git
```

Move into the project directory:

```bash
cd Port-Scanner
```

Install requirements:

```bash
pip install -r requirements.txt
```

---

# 🚀 Usage

Run the scanner:

```bash
python scanner.py
```

Enter target:

```text
Enter target (IP or website):
```

Example:

```text
192.168.1.1
```

or:

```text
example.com
```

Select port range:

```text
Start Port (default 1): 1

End Port (default 100): 100
```
